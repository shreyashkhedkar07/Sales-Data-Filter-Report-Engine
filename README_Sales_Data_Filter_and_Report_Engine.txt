# Sales Data Filter & Report Engine

Beginner-friendly NumPy project based on Project 3 in the supplied project guide.

## Run in Google Colab
1. Open https://colab.research.google.com/
2. Select File -> Upload notebook.
3. Upload `Sales_Data_Filter_and_Report_Engine.ipynb`.
4. Select Runtime -> Run all.

## Features
- Simulates 12 months of sales for 10 stores.
- Calculates quarterly and annual sales.
- Sorts stores by annual sales.
- Filters months and stores using Boolean masks.
- Demonstrates fancy indexing.
- Plots monthly and quarterly sales.
- Exports 120 store-month records to CSV.

All sales data is synthetic and intended for educational use.
